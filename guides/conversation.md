# Using F.E.C.H.A. in any AI conversation

You do not need to create an assistant, GPT, Gem, or project.

## Minimal setup

Provide:

1. `instructions/fecha-instructions.md`;
2. the work you want reviewed;
3. the movement you need.

Example:

> Use F.E.C.H.A. for this conversation. Review the message below and make the decision request and next step explicit without making it more formal.

## For a meeting close

> Apply only the Amarração step. Summarize the decision, next step, owner, timing, and open points.

## For a pilot

> Apply Foco, Enquadramento, and Caminho mínimo. Help me reduce this concept to one useful test before we expand the scope.
