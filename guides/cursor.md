# Using F.E.C.H.A. with Cursor

F.E.C.H.A. can live inside a local product, design, or planning workspace.

## Suggested structure

```text
project/
├── instructions/
│   └── fecha.md
├── inputs/
│   ├── proposal.md
│   ├── meeting-notes.md
│   └── concept.md
└── outputs/
```

Copy the canonical AI instructions into:

`instructions/fecha.md`

Example:

> Read `instructions/fecha.md` first. Review `inputs/proposal.md` using F.E.C.H.A. Do not edit the source file. Write a decision-path review to `outputs/fecha-review.md`.

After review:

> Create a revised proposal in `outputs/`. Preserve the original intent, but make Foco, Caminho mínimo, Handoff de decisão, and Amarração explicit.
